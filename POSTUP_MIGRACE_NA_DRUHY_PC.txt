--------------------------------------------------------------------------------
ČÁST 3: NAPOJENÍ REPOZITÁŘE NA VAŠI GITEU PŘES SSH (NA DRUHÉM POČÍTAČI)
--------------------------------------------------------------------------------

Na druhém počítači, kde už máte funkční SSH klíč do Gitea:

1. Ve webovém rozhraní vaší Gitea vytvořte nový prázdný repozitář:
   - Název repozitáře: gphotos-sync
   - Nezaškrtávejte "Inicializovat repozitář (README/.gitignore)", nechte ho prázdný.

2. Zkopírujte si SSH adresu repozitáře z Gitea, např.:
   - Standardní SSH port 22:
     git@git.vasedomena.cz:uzivatel/gphotos-sync.git
   - Nebo vlastní SSH port (např. 2222):
     ssh://git@git.vasedomena.cz:2222/uzivatel/gphotos-sync.git

3. Otevřete PowerShell nebo terminál na druhém PC ve složce c:\Antigravity\photos
   a spusťte tyto příkazy:

   # Ověření stavu lokálního Git repozitáře
   git status

   # Přidání vzdáleného Gitea repozitáře přes SSH
   git remote add origin git@git.vasedomena.cz:uzivatel/gphotos-sync.git

   # Přejmenování hlavní větve na 'main' (pokud už není) a odeslání kódu do Gitea
   git branch -M main
   git push -u origin main

4. Jakmile je repozitář na Gitea, můžete na druhém PC v Antigravity napsat:
   "Jsme na druhém PC, SSH na Gitea funguje, pojďme nastavit automatické
    vydávání verzí (Releases) a otestovat Gitea updater."


--------------------------------------------------------------------------------
ČÁST 4: JAK POTOM VYDÁVAT NOVÉ VERZE DO GITEA Z DRUHÉHO PC
--------------------------------------------------------------------------------

1. Pro běžné ukládání změn kódu do Gitea (přes SSH):
   git add .
   git commit -m "Popis úpravy"
   git push

2. Pro vydání nové verze instalátoru (Release), kterou si počítač manželky
   sám stáhne a zaktualizuje:
   - V Gitea si vygenerujte API token (Nastavení -> Aplikace -> Vygenerovat token).
   - Spusťte připravený skript:
     .\publish_to_gitea.ps1 `
         -Version "1.0.1" `
         -GiteaUrl "https://git.vasedomena.cz" `
         -Owner "vas_uzivatel" `
         -Repo "gphotos-sync" `
         -ApiToken "VAS_TOKEN" `
         -ReleaseNotes "Nová verze"
